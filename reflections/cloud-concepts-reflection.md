# Cloud Computing Concepts Reflection

Before taking this course, I did not realize that I was already using cloud computing almost every day. I am still new to the topic, but I have learned that many of the apps I use store data and provide services through the cloud.

One cloud service I use regularly is **Google Drive**. I use it to save my school files and access them from my phone or computer. I think it is a **Software as a Service (SaaS)** because I only use the application and Google manages everything behind it. It is also a **Public Cloud** because anyone can create a Google account and use the service.

Another cloud service I use is **Facebook Messenger**. I use it to communicate with my classmates and friends. It is also **SaaS** because I only use the messaging features while Meta manages the system. I believe it uses a **Public Cloud** since it is available to users around the world.

The third cloud service I use is **Canva**. I use it to make presentations and school projects. Like the others, Canva is **SaaS** because I use its online tools without installing professional software. It also uses a **Public Cloud** because anyone can sign up and use it through the internet.

I am still learning how to use **Git** and **GitHub**, but I understand that they are useful for keeping track of changes in projects. They allow users to save different versions of their work and make it easier to work with other people without losing important files. I think GitHub will help me in future programming and cloud computing projects because it keeps everything organized and makes collaboration easier.
