# Cloud Services That Could Host the Linux Server

A Linux server can be migrated to all three major cloud platforms.

| Cloud Provider | Service                |
| -------------- | ---------------------- |
| AWS            | Amazon EC2             |
| Azure          | Azure Virtual Machines |
| GCP            | Compute Engine         |

## AWS

Amazon EC2 could host the Linux server as a virtual machine. The required CPU, memory, storage, networking, and operating system configuration could be selected according to the server's requirements.

## Microsoft Azure

Azure Virtual Machines could be used to migrate the Linux server to Microsoft Azure. Azure supports Linux virtual machines and provides configurable computing resources.

## Google Cloud

Google Compute Engine could host the Linux server as a cloud-based virtual machine. The organization could select an appropriate machine configuration based on the server's CPU, memory, storage, and performance requirements.

---

# Mission Summary

This mission demonstrated that AWS, Azure, and Google Cloud provide similar fundamental cloud capabilities while having different strengths. The best platform depends on the organization's requirements rather than simply choosing the most popular provider.
