## 2. Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest portfolios of cloud services among the three major providers. It provides services covering computing, storage, networking, databases, security, analytics, artificial intelligence, Internet of Things, and many other areas. This makes AWS suitable for organizations with diverse technical requirements.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. Organizations that already use Windows Server, Microsoft 365, Active Directory, and other Microsoft products can benefit from Azure's integration with the Microsoft ecosystem.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is particularly strong in artificial intelligence, machine learning, and Kubernetes. Google developed Kubernetes and provides Google Kubernetes Engine (GKE), while its cloud platform also provides extensive AI and machine learning services.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides a large selection of services and gives users many options for developing and deploying applications. Its global infrastructure and flexible services make it suitable for both small projects and larger applications. It also provides opportunities to learn many different cloud technologies.

## 4. Service Comparison Notes

### Virtual Machines

All three providers offer virtual machines that allow users to run operating systems and applications without maintaining physical servers.

### Object Storage

AWS S3, Azure Blob Storage, and Google Cloud Storage provide scalable object storage for files and other unstructured data.

### Identity Management

AWS IAM, Microsoft Entra ID, and Google Cloud IAM provide mechanisms for managing identities, permissions, and access to cloud resources.

### SQL Database

Amazon RDS, Azure SQL Database, and Cloud SQL provide managed database capabilities that reduce the need for organizations to maintain database infrastructure manually.

### Kubernetes

Amazon EKS, Azure Kubernetes Service, and Google Kubernetes Engine provide managed Kubernetes environments for deploying containerized applications.
