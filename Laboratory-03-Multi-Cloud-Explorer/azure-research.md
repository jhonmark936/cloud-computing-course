# Microsoft Azure Research

## 1. Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides services for computing, storage, databases, networking, security, artificial intelligence, analytics, and application development. Azure is widely used by organizations that already use Microsoft technologies.

## 2. Global Infrastructure

Azure provides cloud infrastructure through regions and availability zones located around the world. Organizations can select regions based on factors such as performance, compliance, data residency, and proximity to users. Azure's global infrastructure allows applications and services to operate across different geographic locations.

## 3. Cloud Management Console

The Azure Portal is a web-based management interface for Azure services. Administrators and developers can use the portal to create virtual machines, configure networks, manage databases, monitor applications, manage identities, and control other cloud resources.

## 4. Four Core Services

### Azure Virtual Machines

Azure Virtual Machines provide virtualized computing resources that can run Windows or Linux operating systems.

### Azure Blob Storage

Azure Blob Storage is an object storage service designed for storing large amounts of unstructured data such as images, documents, videos, and backups.

### Azure Virtual Network

Azure Virtual Network allows cloud resources to communicate securely within an isolated virtual network.

### Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud-based identity and access management service. It helps organizations manage users, identities, authentication, and access to applications and resources.

## 5. Three Advantages

1. Azure has strong integration with Microsoft products and technologies.
2. Azure provides a broad selection of enterprise cloud services.
3. Azure supports hybrid environments, allowing organizations to connect cloud resources with existing on-premises infrastructure.

## 6. Typical Enterprise Use Cases

Azure can be used for:

* Windows Server workloads
* Microsoft 365 integration
* Enterprise application hosting
* Database systems
* Hybrid cloud environments
* Artificial intelligence applications
* Virtual desktops
* Business analytics
* Enterprise identity management
