# Mission 3 Reflection

This mission helped me understand the differences between AWS, Microsoft Azure, and Google Cloud Platform. Among the three platforms, Google Cloud impressed me the most because of its strong focus on artificial intelligence, machine learning, data analytics, and Kubernetes. I also found it interesting that the three providers offer similar basic services while using different names and tools.

AWS, Azure, and Google Cloud have several similarities. All three provide virtual machines, object storage, databases, networking, identity management, security features, monitoring, and scalable infrastructure. They also organize their infrastructure into geographic locations so applications can be deployed closer to users. This allows businesses to improve performance, availability, and scalability without owning all of the physical hardware.

Business requirements are very important when selecting a cloud provider. A company should consider its budget, existing technologies, employees' technical skills, application requirements, security needs, geographic requirements, and expected growth. For example, Azure can be a strong choice for an organization that already depends heavily on Microsoft technologies, while Google Cloud can be attractive for AI and machine learning projects. AWS can be a good general-purpose option because of its broad selection of services.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud platform requires more than simply comparing popular brands. The recommendation should be based on the actual needs and goals of the client. I learned how to analyze a scenario and connect its requirements with appropriate cloud services.

My GitHub Cloud Computing Portfolio also improved through this mission. I added research documents, comparison tables, recommendations, Linux investigation results, and screenshots as evidence. This made my portfolio more organized and demonstrated my ability to document technical research using Markdown and GitHub.
