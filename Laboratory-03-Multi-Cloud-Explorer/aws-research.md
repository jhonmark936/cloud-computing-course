# Amazon Web Services (AWS) Research

## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers many cloud services that organizations can use for computing, storage, databases, networking, security, analytics, and artificial intelligence. AWS allows businesses to create and operate applications without having to maintain all of their own physical infrastructure.

## 2. Global Infrastructure

AWS operates a large global infrastructure organized into geographic Regions and Availability Zones. AWS currently lists 39 geographic Regions and 123 Availability Zones. Each AWS Region contains multiple isolated Availability Zones, which helps organizations design applications for high availability and fault tolerance. AWS also provides infrastructure in many parts of North America, South America, Europe, Asia Pacific, Africa, the Middle East, and other regions.

## 3. Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can create resources, configure services, monitor applications, manage security, and review costs through the console.

## 4. Four Core Services

### Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides resizable virtual servers that can be used to run applications and workloads in the cloud.

### Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used to store files, documents, images, videos, backups, and other types of data.

### Amazon VPC

Amazon Virtual Private Cloud (VPC) allows users to create an isolated virtual network for AWS resources.

### AWS IAM

AWS Identity and Access Management (IAM) controls access to AWS resources by managing users, roles, permissions, and policies.

## 5. Three Advantages

1. AWS provides a very broad range of cloud services for different technical and business requirements.
2. AWS has a large global infrastructure that allows organizations to deploy applications closer to their customers.
3. AWS provides flexible and scalable resources that can support both small applications and large enterprise workloads.

## 6. Typical Enterprise Use Cases

AWS can be used by enterprises for:

* Web and mobile application hosting
* Data storage and backup
* Database hosting
* E-commerce applications
* Machine learning and artificial intelligence
* Disaster recovery
* Enterprise networking
* Large-scale data analytics
